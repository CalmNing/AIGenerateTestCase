# 2026-07-13

## Bug fix: 生成测试用例后历史提示词未保存

**根因**：前端主生成流程已切换为 `generateV2`（4 阶段 pipeline，路由 `POST /testcases/generate-v2` → `PipelineRunner._run_pipeline`）。
旧路径 `model_utils.generate_testcases`（路由 `POST /{session_id}/testcases`）内部会调用 `_upsert_history_prompt` 保存历史提示词，但新 pipeline 路径从未调用，导致生成的提示词不会写入 `HistoryPrompt` 表。

**修复**：在 `backend/app/pipeline/pipeline_runner.py` 中：
- 新增 `_save_history_prompt()` 方法，复用 `utils.helpers._upsert_history_prompt`。
- 从 `run()` 捕获 `original_requirement`（注入技能前），传给 `_run_pipeline`。
- 在 `_run_pipeline` 整体成功后调用保存：剥离技能注入前缀，文档链接场景保存预取后的正文，否则保存用户原始输入（不保存接口 schema 上下文，避免污染历史）。

**注意**：前端在 `pipeline-completed` 事件时已 `setHistoryPromptRefreshKey` 刷新历史侧边栏（App.tsx:1177），后端修复后即可正常显示。
